# Backlog

Attractive-but-optional ideas that are **not** active work. Parking lot for possibilities, not a to-do list. New entries go on top, before the template section. The rules: [guides/log.md §backlog](guides/log.md) — activity discipline is [operation_manual.md §10](operation_manual.md).

One line per idea in your milestone work goes to `PROGRESS.md` ("Deferred ideas"); a *real* backlog entry lives here. Promote an item into the plan only by explicit decision, with the evidence named.

### Example — `--tree` flag for `srcscope`

- **Problem it solves:** Milestone 03 keeps tapping multi-directory scans by hand during testing
- **Depends on milestone:** 03 (batch scanner exists to build on)
- **Evidence that would justify it:** repeated manual directory-tree setup shows up in test notes
- **Effort estimate:** S
- **Decision (date):** —
